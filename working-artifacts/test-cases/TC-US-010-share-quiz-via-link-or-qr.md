## Coverage notes
- AC1–AC10 are each covered by at least one test case; AC4 and AC5 additionally get a combined negative-path test (TC_SHARE_011).
- Out-of-scope items explicitly not covered: multiple concurrent links per quiz (DEC-35), automatic link expiry (DEC-32), attempt/time limits per share (DEC-34), guardian-consent enforcement for joiners (accepted risk, DEC-15/I-3).
- TC_SHARE_002 is marked Automation = No because verifying a downloaded image file and clipboard content is better suited to manual/exploratory verification in this phase.
- Join-side behavior (the student/participant perspective) is covered separately in [TC-US-012-join-quiz-via-link-or-qr.md](TC-US-012-join-quiz-via-link-or-qr.md) to avoid duplication.
